## Step-by-Step Implementation Tasks

### Task 1: Install Vitest in Server & Configure Script
1. Add `vitest` to `server/package.json` `devDependencies`.
2. Add `"test": "vitest run"` and `"test:watch": "vitest"` to `scripts`.
3. Create `server/vitest.config.ts` targeting Node environment:
   ```ts
   import { defineConfig } from 'vitest/config';

   export default defineConfig({
     test: {
       globals: true,
       environment: 'node',
       include: ['src/**/*.test.ts'],
     },
   });
   ```

### Task 2: Refactor `server/src/server.ts` for Test Export
1. Export `app` and `httpServer`:
   ```ts
   export { app, httpServer };
   ```
2. Guard the listen call:
   ```ts
   if (process.env.NODE_ENV !== 'test') {
     httpServer.listen(PORT, () => {
       console.log(`Server listening at http://localhost:${PORT}`);
     });
   }
   ```

### Task 3: Implement Prisma Mock Factory (`server/src/test/prismaMock.ts`)
Create a type-safe mock helper for Prisma models:
- Mock `user`: `findUnique`, `findFirst`, `create`, `update`, `upsert`.
- Mock `room`: `findUnique`, `findFirst`, `create`, `update`, `updateMany`.
- Mock `roomOtp`: `findFirst`, `create`, `update`, `deleteMany`.

### Task 4: Write Unit Tests
1. **`jwt.test.ts` & `guestToken.test.ts`:**
   - Test generating tokens with payload.
   - Test verifying valid tokens.
   - Test error throwing on tampered or expired tokens.
   - Test guest token contains `roomCode` and `email` properties.
2. **`auth.service.test.ts`:**
   - Test user registration hashes password with bcrypt.
   - Test registration throws 409 if user already exists.
   - Test login returns user record on matching password.
   - Test login throws error on invalid credentials.
3. **`room.service.test.ts`:**
   - Test `createRoom` generates nanoid room code and persists to DB.
   - Test `addParticipant` appends user to room participants array.
   - Test `requestOtp` hashes 6-digit OTP and saves `expiresAt` (now + 5 mins).
   - Test `verifyOtp` succeeds with matching code within expiry.
   - Test `verifyOtp` rejects expired OTP.
   - Test `verifyOtp` increments attempts count and locks out after 5 failed attempts.
