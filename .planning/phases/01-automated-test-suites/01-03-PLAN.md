## Step-by-Step Implementation Tasks

### Task 1: Install Vitest & Testing Library in Client
Add dev dependencies to `client/package.json`:
- `vitest`
- `jsdom`
- `@testing-library/react`
- `@testing-library/jest-dom`
- `@testing-library/user-event`
Add scripts:
- `"test": "vitest run"`
- `"test:watch": "vitest"`

### Task 2: Configure Vitest in `client/vite.config.ts` & Setup File
1. Update `client/vite.config.ts` with test configuration:
   ```ts
   /// <reference types="vitest" />
   import { defineConfig } from 'vite'
   import react from '@vitejs/plugin-react'
   import tailwindcss from '@tailwindcss/vite'

   export default defineConfig({
     plugins: [tailwindcss(), react()],
     test: {
       globals: true,
       environment: 'jsdom',
       setupFiles: './src/test/setup.ts',
       css: false,
     },
   })
   ```
2. Create `client/src/test/setup.ts`:
   - Import `@testing-library/jest-dom/vitest`.
   - Setup mocks for `navigator.mediaDevices.getUserMedia`, `navigator.mediaDevices.enumerateDevices`.
   - Clean up DOM after each test.

### Task 3: Implement `GuestJoinModal.test.tsx`
1. Test initial render displays email input and "Send Verification Code" button.
2. Test submitting email triggers `requestOtp` API call and displays 6-digit OTP input boxes.
3. Test typing a digit auto-focuses the next digit box.
4. Test pasting a 6-digit string distributes each digit into the 6 input fields.
5. Test submitting complete code triggers `verifyOtp` mutation.
6. Test error messages display properly on API failure.

### Task 4: Implement Custom Hook Tests
1. **`useMedia.test.ts`:**
   - Test `renderHook(() => useMedia())` invokes `getUserMedia` with default audio and video constraints.
   - Test `toggleAudio()` and `toggleVideo()` toggle track `.enabled` property.
   - Test unmounting the hook stops all media stream tracks.
2. **`useSocket.test.ts`:**
   - Test `renderHook(() => useSocket(token))` connects with `auth: { token }`.
   - Test changing token reconnects with new credentials.
   - Test unmount invokes `socket.disconnect()`.
